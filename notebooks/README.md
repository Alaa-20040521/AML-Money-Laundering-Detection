# Notebooks Documentation

This directory contains the Jupyter Notebooks used throughout the AML project.

## Notebook Workflow

### 1. Data Understanding and Cleaning

**Purpose:** Explore the initial dataset and prepare it for further analysis.

Main tasks:
- Dataset inspection and exploration.
- Missing values analysis.
- Duplicate detection and removal.
- Data type correction.
- Outlier investigation.
- Initial data cleaning.

### 2. Feature Engineering and Model Training

**Purpose:** Prepare the cleaned dataset, engineer model input features, train machine learning models, and evaluate their performance.

Main tasks:
- Feature engineering and selection.
- Data leakage investigation.
- Data splitting and preprocessing.
- Random Forest, XGBoost, and CatBoost training.
- Threshold optimization.
- Model comparison and final evaluation.

## Execution Order

Run the notebooks in the following order:

1. Data Understanding and Cleaning.
2. Feature Engineering and Model Training.

**Note:** Make sure the required dataset files are available before running the notebooks. File paths may need to be adjusted depending on your environment.
