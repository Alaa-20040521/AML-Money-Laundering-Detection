# Model Results

This directory contains the evaluation results and visualizations generated during the AML machine learning project.

## Model Evaluation

Three machine learning models were trained and evaluated:

- Random Forest
- XGBoost
- CatBoost

### Validation Results

The following metrics were calculated on the validation set using Average Precision (PR-AUC) and ROC-AUC.

| Model | PR-AUC (Average Precision) | ROC-AUC |
|---|---:|---:|
| Random Forest | 0.6817 | 0.8820 |
| XGBoost | 0.7228 | 0.8957 |
| CatBoost | 0.7447 | 0.9206 |

### Model Selection and Threshold Optimization

The models were compared using validation data under a minimum Recall requirement of 0.75.

For each model, the classification threshold was optimized to maximize Precision while satisfying the minimum Recall requirement. F1-score was used as a tie-breaker.

Based on the recorded evaluation results:

- **Selected Model:** CatBoost
- **Selected Decision Threshold:** `0.57`

### Final Test Results

The selected model was evaluated on the held-out test set using the threshold determined from validation data.

| Metric | Score |
|---|---:|
| Accuracy | 85.89% |
| Precision | 66.69% |
| Recall | 78.02% |
| F1-score | 71.91% |
| PR-AUC (Average Precision) | 75.83% |
| ROC-AUC | 92.54% |

These results represent performance on the synthetic test dataset and should not be interpreted as expected performance on real-world banking transactions.
