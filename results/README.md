# Model Results

This directory contains the evaluation results and visualizations generated during the AML machine learning project.

## Model Evaluation

Three machine learning models were evaluated:

- Random Forest
- XGBoost
- CatBoost

### Validation Results

| Model | PR-AUC | ROC-AUC |
|---|---:|---:|
| Random Forest | 0.6817 | 0.8820 |
| XGBoost | 0.7228 | 0.8957 |
| CatBoost | 0.7447 | 0.9206 |

### Selected Model

CatBoost was selected based on its validation performance and threshold optimization.

Selected decision threshold: `0.57`.

### Final Test Results

| Metric | Score |
|---|---:|
| Accuracy | 85.89% |
| Precision | 66.69% |
| Recall | 78.02% |
| F1-score | 71.91% |
| PR-AUC | 75.83% |
| ROC-AUC | 92.54% |
